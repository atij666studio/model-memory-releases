# Model Memory

**Stateful hardware models by ATIJ Studio. Free.**

A normal amp or hardware capture is a snapshot: the same input always gives the same output.
Real gear remembers what you just played: tube bias shifts after big hits, supplies sag and
recover, compressors release more slowly after working hard, and circuits drift as they warm up.
Model Memory captures that history. Its memory cells have learned attack and release times you can see
and control (Depth, Time, Recovery, Thermal, Freeze, Preheat), and you can train models of your
own gear inside the plugin.
